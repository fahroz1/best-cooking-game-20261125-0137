# Warung Rush: Dapur Kilat

Game masak 2D yang berjalan offline di browser desktop. Kamu adalah koki di sebuah
warung kecil: ambil bahan di pantry, potong di talenan, masak di kompor, rakit
hidangan di meja plating, lalu antar piring lengkap ke jendela sajian sebelum
timer pesanan habis. Lima resep warung, kombo beruntun, dan shift 3 menit yang
makin sibuk. Kontrol keyboard (WASD/panah + E) dan mouse (klik untuk berjalan).
Semua gambar digambar di canvas dan semua suara disintesis WebAudio — tanpa
file eksternal dan tanpa network sama sekali.
